# Price Market local guides

Local editorial guides are generated from `data/local-guides.json` and approved records in `businesses.js`. Keep the source data editorial: each guide needs original introduction and section copy, and each item must reference an existing approved, non-demo business and one of its current listings. The file is deliberately empty until there is enough genuine approved content.

## Source format

Each guide has a unique `slug`, `citySlug`, `kind`, `title`, `metaTitle`, `description`, `h1`, `intro`, `lastUpdated`, and two or more useful sections. Each section has a distinct `title`, substantive `intro`, and `items` array. Item references use `businessSlug`, `listingType`, and either a stable `listingId` or exact `listingTitle`. Optional `startDate`, `endDate`, and `lastVerified` use YYYY-MM-DD dates. References are resolved against the live profile/listing data at generation time; copied listing text is not trusted as the content source.

## Publishing and freshness

A guide route is generated only while it contains at least one current approved real listing. It receives `index,follow`, a self-canonical URL, and sitemap membership only after it has at least four distinct current items, a unique introduction of at least 40 words, unique title and description, and at least two sections whose editorial introductions contain at least 18 words. Below that indexing threshold it is generated with `noindex,follow` and omitted from the sitemap. If every item is expired, future-dated, stale, missing, or demo-only, the page is removed if it was generated by this utility.

For deals and Happy Hours, include an end date or a recent verification date. Promotion references with neither are excluded. Verifications older than 30 days are excluded. Expired end dates and future start dates are excluded for every listing type. Update `lastUpdated` when editorial content is reviewed. Only generated files carrying the utility marker are eligible for cleanup.

## Regenerate

After a human has approved the underlying business/listing and reviewed the guide source, run:

```sh
node scripts/generate-local-seo-pages.js
```

Review generated HTML and `sitemap.xml`, run `node --test scripts/*.test.js business-onboarding.test.js`, and open a PR. There are currently no eligible guides because the approved profile dataset has no real businesses; the Keystone Pizza profile is demo-only.
